# Source notes

This directory is the editorial source for the concept map on kusahata.com.

Write freely about interests, work, research, habits, places, objects, values,
and contradictions. The deployment workflow sends these notes and selected
public GitHub metadata to OpenAI, then writes a structured concept map to
`data/concepts.json`.

Only add information that may safely influence the public website. Do not put
passwords, API keys, private contact details, or confidential material here.

## Current direction

- AI as a tool for discovering patterns in personal information
- Web design as a way to express identity through interaction
- A personal landing page built from connected words rather than a biography
